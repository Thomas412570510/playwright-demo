# 🚀 終極版：人機協作自動化測試 SOP (最高指令)

**【⚠️ AI 觸發條件與最高指令】**
當使用者在對話中說出 **「我要錄腳本」**、**「幫我錄製」** 或任何類似詞彙時，AI 代理人 (Agent) **必須無條件加載本技能**，並嚴格按照以下 SOP 推進流程，絕對不可偏離。

---

## 【第一階段：環境啟動與錄製】
1. **[使用者]** 接收 Agent 的 zip 專案檔案。
2. **[使用者]** 下載並解壓縮至電腦。
3. **[使用者]** 使用 VSCode 開啟專案資料夾。
4. **[使用者]** 對 Agent (AI) 下達指令：「我要錄腳本」。
5. **[Agent]** 接收指令後，立刻為使用者執行我們打造的特製錄製引擎（請提示使用者或是直接代勞執行 `npm run codegen`）。
6. **[使用者]** 開始在彈出的網頁上手動點擊、錄製腳本。
7. **[系統] (⭐ 截圖防護)**：在使用者點擊的同時，系統會在背景自動拍下每一步的截圖。當視窗關閉，系統會自動把截圖打包成 `trace.zip`，作為 Agent 未來比對的鐵證。

## 【第二階段：自動化測試與 AI 抓蟲】
8. **[Agent]** 拿到錄好的腳本後，立刻啟動機器人進行自動化測試（執行 `npm run test`）。
9. **[判定點] 測試過程中是否有報錯？**
   * 🚨 **如果「有報錯」：**
      1. **(⭐ 截圖防護)**：系統在崩潰瞬間，自動拍下高畫質的「急救截圖」與「黑盒子崩潰軌跡」。
      2. **[Agent 第一階段除錯：看圖抓蟲]**：Agent 拿到急救截圖分析畫面哪裡出錯，並自動調整修改腳本。修改完成後，回到**第 8 步**重新測試。
      3. **(防呆機制一)**：此「看圖抓蟲」迴圈最多執行 **3 次**。
      4. **[Agent 第二階段除錯：看影片抓蟲]**：若看圖修改 3 次皆失敗，Agent 必須去調閱**「影片檔 (.mp4)」**進行深度的動態分析。修改完成後，同樣回到**第 8 步**重新測試。
      5. **(防呆機制二)**：此「看影片抓蟲」迴圈最多也執行 **3 次**。
      6. **[最終回報]**：若上述兩階段（共 6 次嘗試）皆無法解決，Agent 必須停止嘗試，並直接向使用者回報**「錯誤訊息 + (錯誤急救截圖) + 影片檔」**，交由人類決策。
   * ✅ **如果「無報錯」：**
      1. 腳本順利跑完，進入第三階段。

## 【第三階段：確認與隱私收尾】
10. **[Agent]** 確認腳本運行完美、毫無 Bug。
11. **[判定點] 使用者有無其他指示？**
    * 💬 **如果「有指示」**：
       1. **[Agent]** 依據使用者的要求修改腳本程式碼。
       2. 修改完畢後，退回**第 8 步**重新測試，確保修改沒弄壞腳本。
    * 🔇 **如果「無指示」**：
       1. 進入最後一步收尾。
12. **[Agent]** 進行安全收尾，將腳本中出現的私人資訊（如帳號密碼）抽離，寫進 `.env` 檔中保護起來。
13. **[流程結束]** 完美收工！🎉
