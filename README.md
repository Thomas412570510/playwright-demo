# Playwright 自動化測試專案 - 新電腦環境設定指南

如果您要把這個專案移到另一台全新的電腦上執行，請務必按照以下步驟設定，才能確保環境與原本一模一樣（包含 D 槽集中管理機制的設定）。

## 步驟一：複製必備檔案
1. **複製專案本體**：將這個 `demo4` 資料夾整個複製到新電腦。
2. **複製 D 槽核心環境**：將原本電腦上的 `D:\PlaywrightData` 資料夾，**完整複製到新電腦的 D 槽相同位置**。
   *(這非常重要！因為我們把 `.env` 環境變數檔都放在這裡了。如果不複製過來，專案啟動時會找不到設定。)*

## 步驟二：安裝 Node.js
如果新電腦是一台全新的機器，請先到 [Node.js 官方網站](https://nodejs.org/zh-tw) 下載並安裝 LTS (長期維護版)。

## 步驟三：安裝專案套件與瀏覽器引擎
用 VSCode 打開 `demo4` 資料夾，然後開啟終端機 (Terminal)，依序執行以下兩行指令：

```bash
# 1. 根據 package.json 把我們用到的套件 (包含轉檔工具) 抓下來
npm install

# 2. 讓 Playwright 重新下載專用的瀏覽器引擎 (它會乖乖載到 D 槽)
npx playwright install
```

## 步驟四：驗證安裝是否成功
如果上面的步驟都做完了，您可以直接輸入測試指令：

```bash
npm run test
```

如果看到綠色的 Pass，且資料夾成功產出 `.mp4` 影片，恭喜您！新電腦的環境已經完美架設完畢！🎉
